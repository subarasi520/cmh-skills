# 研究协议（模板）

在任何模型给要报告的数据打标签之前填好本协议。用 `cmh_protocol.py freeze` 把它和定义、提示词、配置、
规则文件一起冻结，并提交锁文件。之后只能通过文末的“偏离记录”修改。

## 1. 问题与结论

- **分析单位**：结论表的一行是什么（一个概念、一个词形、一篇文档、一位发言人……）。
- **每条实例判什么**：读者对每条检索到的实例要做的判断。
- **判定怎样汇总成结论**：最早一例／各组占比／有无／组间比较／编码后进统计模型。
- **把结论写成一句带空格的话**，例如：“单元＿＿在＿＿中最早见于＿＿（证据：＿＿）”。

## 2. 研究对象

- 哪些在范围内、哪些不在。已知的边界情况。
- 边界情况由谁裁定，裁定记录在哪里。

## 3. 语料层与证据层级

| 层 | 来源 | 覆盖（年代、语域） | 许可／获取方式 | 能支撑什么 | 层级名 |
|---|---|---|---|---|---|
| 例：全文 | | | | 来自实际实例的数值 | |
| 例：检索接口 | | | | 只能给上界 | |
| 例：频率序列 | | | | 只看趋势，不给数值 | |

- 层级从强到弱排序。低层级不能覆盖高层级。
- 已知缺口：没有任何来源覆盖的年代或语域。

## 4. 观察窗与删失

- 每一层覆盖的起止时间。
- 落在窗口边缘的数值按界限报告，不当作首现。

## 5. 候选与抽样框

- 语料提名：扫描规则与过滤条件，在看结果之前定好。
- 完整使用的封闭名单（哪一份、哪一版）。
- 模型枚举只用于语料提名不到的部分；枚举出来的条目必须再到语料里找到实例。
- 粗筛模型（如果有）：只当筛子，不当判据；它的全部输出都要留存。

## 6. 检索

- 每个单元的检索规则；每个单元每个时期最多取多少条实例；给多少上下文；如何去重。
- 检索由代码完成。不让任何模型提供年代、出处或例句。

## 7. 定义或编码手册

- 谁起草，谁审定。只用 status = approved 的行。

## 8. 判读层

- 模型与版本、后端、参数（温度 0）、提示词文件、标签集、解析规则。
- 判读层看不到什么、为什么（例如不给年代，免得它按“这个意思大概什么时候出现”来推）。

## 9. 汇总与弃权

- 准确的规则（例如：最早一条判为 TARGET 的实例；至少 N 条支持实例）。
- 什么情况下不下结论（弃权），弃权怎样报告。

## 10. 分流

- 规则文件。未标记结论的抽查数量与随机种子。

## 11. 审计层

- 模型与配置（与判读层不同）、它能看到什么、判定标签。
- 被否决的证据怎么处理（删去后重新汇总，或交给人）。

## 12. 人工标注

- **试标**：条目、分层（语言 × 类别）、两名及以上独立标注者、按类别算一致度。
- **评估**：哪些条目（各条件的产出，去重、隐去来源、打乱顺序）、几位读者、多数决规则。
- 独立性：标注者看不到模型输出、彼此的答案和答案键。
- 裁决：谁来定，怎样记录。

## 13. 对照条件与基线

- 验证性比较（现在就定）与探索性比较（报告时注明）。
- 一个简单基线（例如字符串匹配），用来说明模型层多做了什么。

## 14. 指标

- 每一层：剩余错误率、捕获率、误推翻率、精确率（Wilson 区间）。
- 分流：标记与未标记的错误率、风险比。
- 一致度：κ、AC1、正类与负类特异一致率，按语言、按类别。
- 漏报：从弃权／判否池中抽样的数量。
- 成本与规模：每一层、每个模型的调用次数。

## 15. 解读规则（在看到任何结果之前写好）

- 每个验证性比较：什么结果对应什么结论。
- 模型层在什么条件下可以不经全量人工复核（例如：每个分层与人的一致度不低于＿＿）。

## 16. 报告

- 每个数字都来自结果文件，并用 `cmh_numbers.py` 核对。
- 每个结论都附上证据层级和该层级实测的错误率。
- “没有显著差异”不写成“相同”。

## 17. 数据处理

- 每个来源的版权与使用条款；个人信息；需要时的伦理审查。
- 什么存在哪里；什么绝不提交到仓库（语料、答案键、API 密钥）。
