# 常见失误及其检查方法

用模型阅读语料时反复出现的失误。每一种都列出症状、检查方法，以及工作流程里防止它的环节。

## 证据

| 失误 | 症状 | 检查／预防 |
|---|---|---|
| **把模型的记忆当证据** | 年代、出处或例句，找不到任何检索到的实例支持 | 数值只来自检索到的实例；判读层看不到年代；核对规则“有结论 → 证据编号不能为空”；对实例表做外键核对 |
| **把子串匹配当证据** | 词形出现在更长的词或名称里面（短词形是复合词的一部分；分词后字符串跨过了词的边界） | 逐条判读实例；提示词和标注说明里写明“只是更长词语的一部分 → OTHER”；对短词形设分流规则 |
| **模糊检索的幻影命中** | 检索接口返回了命中数，但样例文本里根本没有这个词形 | 对样例做字面核对（“证据保真”仪表）；命中数只当界限；无样例可查时默认不通过 |
| **把窗口边缘当首次出现** | 很多值落在某个来源的第一年；时滞呈现出只是算术结果的趋势 | 用 `--window-start` 标出删失；窗口边缘的值按界限报告；不混进年代或时滞的分布 |
| **总能给出答案的基线** | 字符串匹配给每个单元都“定了年”，包括根本没有真实实例的 | 把弃权当作结果报告；在同一份真值上与判读层比较 |

## 候选

| 失误 | 症状 | 检查／预防 |
|---|---|---|
| **覆盖面被枚举封顶** | 候选清单只是模型或人碰巧想到的；让模型继续列，它会反复给出已经给过的条目的变体 | 先用语料提名和封闭名单；只在语料提名不到的地方用枚举 |
| **粗筛输出没有留存** | 漏斗数字无法从记录里复现；某一环节的输出文件被覆盖或从未保存 | 每一条粗筛输出和调用记录都留存；漏斗从记录里数 |
| **碎片被当作单元** | 最终结论表里出现半截词或被截断的短语 | 粗筛标出碎片；对单元长度或形式做核对；人审定义 |

## 模型

| 失误 | 症状 | 检查／预防 |
|---|---|---|
| **只在一个切片上选配置** | 判读层只在一种语言或一个类别上验证过，却用于全部 | 部署前按语言 × 类别试标；按分层选择 |
| **把置信度当停止标准** | 高置信度的结论跳过复核，有把握的错误永远不会被看到 | 按写明的规则分流；无论置信度高低都对未标记结论随机抽查 |
| **只有自审** | 同一个模型检查自己的输出，并同意自己 | 用配置不同的模型审计；既测它捉到的错，也测它的精确率 |
| **盲目相信更强的审计** | 审计推翻了很多本来成立的结论 | 在人的真值上测误推翻；报告捕获率的同时报告精确率 |
| **提示词漂移** | 同一张表里的标签来自好几个版本的提示词 | 台账汇总显示每层的提示词版本数；修改后协议锁会阻止运行 |
| **把读不懂的回答当答案** | 自由文本的回答被宽松地解析成标签 | 严格匹配标签；无法解析的回答计数并报告，不去猜 |

## 人

| 失误 | 症状 | 检查／预防 |
|---|---|---|
| **定义由模型写、没人审** | 读者确认“符合给定定义”，而定义本身是错的 | 定义需要 `status = approved`；`cmh_judge.py` 拒绝其他定义 |
| **只有一个标注者** | 没有人与人的一致度，人与模型的数字就没有参照 | 从试标开始就有两名及以上标注者 |
| **卷子泄题** | 发出去的卷子带着模型答案或来源标签 | `cmh_sheet.py` 拒绝危险列；答案键另存 |
| **卷面混杂** | 给某种语言的卷子里混进了别的语言的条目 | 发卷前用 `--require lang=xx` 和 `--summarize` 检查 |
| **把分歧当噪声** | 边界情况靠多数决了事，没有人决定研究对象到底是什么 | 由研究者裁定、记录，并适用于所有类似条目 |

## 流程与报告

| 失误 | 症状 | 检查／预防 |
|---|---|---|
| **“全绿”的交付物** | 自动运行报告覆盖率百分之百、测试全部通过，而数据在单元之间串了行 | 外键、行数和蕴含核对；与上一个确认过的版本比对；亲手读一部分样本 |
| **先看结果再定规则** | 协议在看过结果之后才写，或者被改过 | 评估运行前冻结并提交锁文件；偏离记录 |
| **分母错了** | “n 个中 k 个”的 n 数的东西和正文说的不一样 | 分母由脚本算出；写明 n 数的是什么 |
| **抽查并不随机** | 所谓随机抽查其实来自同一批次 | 对全部未标记结论做带种子的抽样，抽样前先排序 |
| **人工输入被覆盖** | 一次重建悄悄替换了手工录入的裁定 | 人工输入只有一个入口；`cmh_check.py diff --fail-on-change` |
| **护栏被上游绕过** | 依赖某个标签的护栏，在前一步改了标签名之后失效 | 对结果做核对（`implies`），而不只核对标签；版本比对 |
| **手算的数字** | 正文里有脚本产不出的数；四舍五入做了两次 | 数字只来自脚本；`cmh_numbers.py check`，包括未登记数字的扫描 |
| **把“不显著”写成“相同”** | 不显著的差异被报告成持平 | `cmh_evaluate.py compare` 会打印提醒；复核措辞 |
| **分母不同的比例并排比** | 把精确率和误推翻率并排放着当作可比 | 写明每个比例的分母 |
| **编造或没读过的引用** | 引用的文献不存在，或者并没有说被引用的那句话 | 只引用读过全文的文献；每条引用都对照原文核对 |
